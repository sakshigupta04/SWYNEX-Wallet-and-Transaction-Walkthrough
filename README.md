## Task 2: Wallet and Transaction Walkthrough

### Objective

The objective of this task is to understand how a blockchain wallet works and how a blockchain transaction is created, submitted, and verified using a safe test network or simulated environment.

## 1. What is a Blockchain Wallet?

A blockchain wallet is a digital tool used to interact with a blockchain network. It allows users to manage blockchain accounts and send or receive digital assets.

A wallet generally uses:

* Public address — used to receive assets.
* Private key/seed phrase — used to control the wallet and must be kept secret.
* Network — the blockchain environment on which transactions take place.

## 2. Test Network

For this task, a test network or simulated environment is used instead of real cryptocurrency.

Test networks are useful for learning because they allow users to practice transactions without using real funds.

## 3. Wallet Setup

The wallet was prepared for a test-network transaction.

Basic steps:

1. Open the wallet.
2. Create or select a test account.
3. Select the appropriate test network.
4. Obtain test funds if required.
5. Check the wallet address and balance.

## 4. Transaction Walkthrough

The transaction process was studied using the following steps:

1. Open the wallet.
2. Select the test network.
3. Enter the recipient's test address.
4. Enter the test amount.
5. Review the transaction details.
6. Confirm the transaction.
7. Wait for the transaction to be processed.
8. Check the transaction status.
9. Verify the transaction using the available transaction details or test-network explorer.

## 5. Transaction Details

The important details of a blockchain transaction can include:

* Sender address
* Recipient address
* Transaction amount
* Transaction fee
* Transaction hash
* Block number
* Transaction status

The transaction hash is a unique identifier that can be used to locate and verify a transaction on a blockchain explorer.
